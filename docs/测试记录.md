# 验证记录（v0.1.0）

## 自动测试

| 项目 | 结果 |
| --- | --- |
| 测试数量 | 150 个（149 通过，1 个联网 Shazam 测试默认跳过；未安装可选 ShazamIO 时另有 1 个客户端测试跳过） |
| `bgm_audit/` 覆盖率 | 分支覆盖约 97–98%（CI 门槛 85%） |
| 平台 | GitHub Actions：Ubuntu、macOS、Windows × Python 3.12，FFmpeg 来自各平台包管理器 |
| 静态检查 | ruff（lint + format）、mypy strict（`bgm_audit/`）、gitleaks（完整 Git 历史） |

测试全部离线：用固定种子合成的原创音频驱动真实 FFmpeg + audfprint；Shazam 全部 Mock。真实 Shazam 命中没有验证，不宣称第三方服务当前可用。

## 覆盖范围

| 项目 | 验证方式 |
| --- | --- |
| 参考音乐导入与指纹建库 | 合成 WAV；MP3 / FLAC 转码后导入；重复导入、静音、超长、曲库上限被拒绝 |
| 本地匹配 | 同曲片段、单窗口多曲、两首歌叠加、未入库音乐与噪声不命中 |
| 视频时间轴 | 采样点精确切片、窗口偏移、音轨晚于 / 早于画面、多音轨只审第一轨 |
| 异常输入 | 无音轨、空文件、损坏文件、截断文件、缺少 FFmpeg、FFmpeg 超时、缺少 audfprint 源码 |
| 合并规则 | 相邻窗口合并、容差边界、不跨引擎 / 歌曲 / 未命中窗口、保留全部证据 |
| 审核规则 | README 规则表逐行、汇总优先级、「不通过」不被冲突降级、用途首尾空白、`verified` 严格为 true |
| 外部识别失败 | Mock 网络、超时、429、接口变更（不重试）、请求间隔、客户端创建失败 |
| 存储与报告 | SQLite 持久化、旧库迁移、搜索通配符转义、复查日志快照、CSV 防注入、JSON |
| 设置 | 参数校验、损坏 / 旧版本设置文件回退、`BGM_DATA_DIR` |
| 中文界面 | Streamlit AppTest：五个页面、步骤导航、一键演示、片段预览、保存复查、导出 |
